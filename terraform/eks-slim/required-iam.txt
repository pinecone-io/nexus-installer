# IAM actions the eks-slim `terraform apply` performs, checked by check-iam.sh
# before apply. Starter list derived from the module's resources; harden it with
# an iamlive capture of a known-good apply. One action per line; # starts a comment.
#
# NOTE: a few actions are resource-scoped in tight policies (notably iam:PassRole,
# limited to the cluster/node roles). check-iam.sh simulates against "*", so a
# scoped-but-sufficient policy can show DENIED here — treat those as "confirm the
# scope", not a hard failure.
