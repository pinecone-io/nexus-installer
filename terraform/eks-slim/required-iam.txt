# IAM actions the eks-slim `terraform apply` performs, checked by check-iam.sh
# before apply. One action per line; # starts a comment; commented actions are
# NOT checked. Re-derive from an apply's IAM calls when the module changes.
#
# Some actions are inline-authorized at resource create and never surface as
# their own API call (iam:PassRole, *:CreateTags/TagRole/TagResource,
# s3:ListBucket/GetBucketLocation) — required nonetheless, so keep them.
#
# iam:PassRole is resource-scoped in tight policies (the cluster/node roles);
# check-iam.sh simulates against "*", so a scoped-but-sufficient policy can show
# DENIED here — confirm the scope rather than treating it as a failure.
